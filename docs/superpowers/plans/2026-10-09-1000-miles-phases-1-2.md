> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the Lisa build/transfer pipeline works, and build a fully host-tested, Lisa-Pascal-portable rules engine and AI for the 1000 Miles card game.

**Architecture:** `src/MILES-LOGIC.TEXT` is one Pascal unit (`MilesLogic`) with no dependencies. It compiles unchanged under Free Pascal on the Mac (`-Mtp`, 16-bit `integer`, range/overflow checks on) and, later, under Lisa Pascal in Workshop. A Makefile copies it to `build/mileslogic.pas` for host builds. Host tests and a seeded simulator exercise it. A Python lint enforces the conservative Pascal subset.

**Tech Stack:** Lisa Pascal (Workshop 3.0), Free Pascal (`fpc`, host only), GNU make, Python 3 (`pyserial` for transfer, stdlib `unittest` for the lint tests).

**Spec:** `docs/superpowers/specs/2026-10-09-1000-miles-design.md`

**Scope note:** Phases 3-5 (UI, playable game, polish) and Phase 6 (Risk) get their own plans after Phase 1's findings are in. This plan ends with `MILES-LOGIC` compiling on a real Lisa.

## Global Constraints

- Card deck is exactly 106 cards: 46 distance (25x10, 50x10, 75x10, 100x12, 200x4), 18 hazards (Accident 3, OutOfGas 3, Flat 3, Limit 4, Stop 5), 38 remedies (Repairs 6, Gas 6, Spare 6, EndLimit 6, Go 14), 4 safeties.
- Two players, hand of 6, trip target exactly 1000 miles, at most two 200-mile cards per player per hand.
- Names and art are original; the product name is "1000 Miles" (never "Mille Bornes") in code, UI strings and docs.
- `MILES-LOGIC.TEXT` has no `uses` clause (no Lisa units), takes an injected RNG seed, and stays inside the Lisa Pascal subset: 16-bit `integer` (use `longint` for anything that can exceed 32767), **no boolean short-circuit assumed** (never write a condition whose right side is only safe when the left side decides the result), no `exit(...)`, `inc`/`dec`, `break`/`continue`, `shl`/`shr`, `otherwise`, `Result`, or `{$...}` directives.
- Host build flags: `-Mtp -Cr -Co` (range and overflow checking on). Every host test run must pass with them.
- Source files are LF on the Mac; the transfer script converts to the Lisa's CR.
- Commit messages end with: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`

## Rule decisions (R1, R2, R4 confirmed by the user on 2026-10-09; R3, R5 still unconfirmed)

- **R1 (confirmed)** Playing a safety on your own turn gives you an extra turn (draw + play). Constant `SafetyExtraTurn` in the unit.
- **R2 (confirmed)** Coup fourré: you play the safety out of turn, the hazard is undone completely (your pile returns to its prior state, so you keep moving without needing a Go card), you draw a replacement card, and it becomes your normal turn (draw + play), one move, not two in a row.
- **R3** A hazard may only be played on an opponent who can currently move (`CanMoveNow`), except Speed Limit, which needs only "not already limited and no Right of Way".
- **R4 (confirmed)** Scoring: 1 point per mile; 100 per safety; +300 more per safety played as a coup fourré; +300 for all four safeties; trip complete +400; delayed (trip completed after the draw pile ran out) +300; safe trip (no 200s) +300; shutout (opponent has 0 miles) +500. No extension.
- **R5** The hand ends when someone reaches exactly 1000, or when the draw pile is empty and both hands are empty.

## Review Focus

Failure modes the spec implies but no obvious happy-path test covers, most likely first. Each has a test in the task named.

1. RNG seed edge cases (0, negative, minimum/maximum `longint`) must give a valid, non-degenerate shuffle. A Park-Miller generator seeded with 0 stays 0 forever (Task 3).
2. Overshooting 1000 miles (975 + 50) must be refused; 975 + 25 must win. Third 200-mile card refused (Task 4).
3. Draw pile exhausted: a player with an empty hand is skipped; both empty ends the hand; no stuck turn or crash (Task 5).
4. Coup fourré must restore the exact prior battle/limit state, work for Stop/Limit via Right of Way, and not hang when the coup uses the player's last card with the pile empty (Task 5).
5. Safeties: playing one must cure the matching hazard, Right of Way must clear both Stop and Limit, and a safety must never be playable on the opponent (Tasks 4-5).

{ Park-Miller minimal standard generator using Schrage's method: no 32-bit overflow. }
function NextRand(var seed: longint): longint;
var hi, lo: longint;
begin
  hi := seed div 127773;
  lo := seed mod 127773;
  seed := 16807 * lo - 2836 * hi;
  if seed <= 0 then seed := seed + 2147483647;
  NextRand := seed
end;

{ Any longint becomes a seed in 1..2147483646 (0 would make the generator stick at 0). }
function NormSeed(s: longint): longint;
begin
  if s < 0 then s := -(s + 1);
  s := s mod 2147483647;
  if s = 0 then s := 1;
  NormSeed := s
end;

function RandBelow(var g: Game; n: integer): integer;
begin
  RandBelow := NextRand(g.rng) mod n
end;

function RemainingDeck(var g: Game): integer;
begin
  RemainingDeck := NumCards + 1 - g.deckNext
end;

procedure DealTo(var g: Game; p: integer);
begin
  if g.deckNext <= NumCards then begin
    g.pl[p].handN := g.pl[p].handN + 1;
    g.pl[p].hand[g.pl[p].handN] := g.deck[g.deckNext];
    g.deckNext := g.deckNext + 1
  end
end;

procedure NewGame(var g: Game; seed: longint);
var i, j, c, n, p: integer; k, t: CardKind;
begin
  g.rng := NormSeed(seed);
  n := 0;
  for k := ck25 to sfRoW do
    for c := 1 to KindCount(k) do begin
      n := n + 1;
      g.deck[n] := k
    end;
  for i := NumCards downto 2 do begin
    j := 1 + RandBelow(g, i);
    t := g.deck[i];
    g.deck[i] := g.deck[j];
    g.deck[j] := t
  end;
  g.deckNext := 1;
  for p := 0 to 1 do begin
    g.pl[p].battle := ckNone;
    g.pl[p].limited := false;
    g.pl[p].miles := 0;
    g.pl[p].n200 := 0;
    g.pl[p].handN := 0;
    for i := 0 to 3 do begin
      g.pl[p].safe[i] := false;
      g.pl[p].viaCoup[i] := false
    end
  end;
  for i := 1 to HandSize do begin
    DealTo(g, 0);
    DealTo(g, 1)
  end;
  g.discardTop := ckNone;
  g.turn := 0;
  g.ph := phDraw;
  g.tripBy := -1;
  g.delayedTrip := false;
  g.gone := 0;
  g.coupSeat := -1;
  g.coupHazard := ckNone;
  g.prevBattle := ckNone;
  g.prevLimited := false
end;

function HandIndexOf(var p: PlayerState; k: CardKind): integer;
var i, r: integer;
begin
  r := 0;
  for i := p.handN downto 1 do
    if p.hand[i] = k then r := i;
  HandIndexOf := r
end;

procedure RemoveFromHand(var g: Game; s, idx: integer);
var i: integer;
begin
  for i := idx to g.pl[s].handN - 1 do
    g.pl[s].hand[i] := g.pl[s].hand[i + 1];
  g.pl[s].handN := g.pl[s].handN - 1;
  g.gone := g.gone + 1
end;

{ RULE R5: ends the hand at exactly 1000, or when the pile and both hands are empty. }
procedure EndTurn(var g: Game);
var nxt: integer;
begin
  if g.pl[g.turn].miles = TripMiles then begin
    g.tripBy := g.turn;
    g.delayedTrip := (g.deckNext > NumCards);
    g.ph := phOver
  end
  else begin
    nxt := Opp(g.turn);
    if g.deckNext > NumCards then begin
      if (g.pl[0].handN = 0) and (g.pl[1].handN = 0) then g.ph := phOver
      else begin
        if g.pl[nxt].handN > 0 then g.turn := nxt;
        g.ph := phDraw
      end
    end
    else begin
      g.turn := nxt;
      g.ph := phDraw
    end
  end
end;

procedure ExtraTurn(var g: Game);
begin
  if SafetyExtraTurn and ((g.deckNext <= NumCards) or (g.pl[g.turn].handN > 0)) then
    g.ph := phDraw
  else
    EndTurn(g)
end;

procedure ApplySelf(var g: Game; s: integer; k: CardKind);
begin
  with g.pl[s] do begin
    if IsDistance(k) then begin
      miles := miles + DistValue(k);
      if k = ck200 then n200 := n200 + 1
    end
    else if k = rmGo then battle := rmGo
    else if (k = rmRepairs) or (k = rmGas) or (k = rmSpare) then battle := k
    else if k = rmEndLimit then limited := false
    else begin
      safe[SafetyIdx(k)] := true;
      if (k = sfAce) and (battle = hzAccident) then battle := rmRepairs;
      if (k = sfTank) and (battle = hzOutOfGas) then battle := rmGas;
      if (k = sfPunct) and (battle = hzFlat) then battle := rmSpare;
      if k = sfRoW then begin
        limited := false;
        if battle = hzStop then battle := rmGo
      end
    end
  end
end;

      g.prevBattle := g.pl[o].battle;
      g.prevLimited := g.pl[o].limited;
      if k = hzLimit then g.pl[o].limited := true
      else g.pl[o].battle := k;
      if HandIndexOf(g.pl[o], SafetyFor(k)) > 0 then begin
        g.coupSeat := o;
        g.ph := phCoup
      end
      else EndTurn(g)
    end
    else begin
      ApplySelf(g, s, k);
      if IsSafety(k) then ExtraTurn(g) else EndTurn(g)
    end
  end
end;

{ RULE R2: a coup undoes the hazard, draws a replacement, and the victim takes the next turn. }
procedure ResolveCoup(var g: Game; useCoup: boolean);
var c, i: integer; sf: CardKind;
begin
  if g.ph = phCoup then begin
    c := g.coupSeat;
    sf := SafetyFor(g.coupHazard);
    i := HandIndexOf(g.pl[c], sf);
    g.coupSeat := -1;
    if useCoup and (i > 0) then begin
      RemoveFromHand(g, c, i);
      g.pl[c].safe[SafetyIdx(sf)] := true;
      g.pl[c].viaCoup[SafetyIdx(sf)] := true;
      g.pl[c].battle := g.prevBattle;
      g.pl[c].limited := g.prevLimited;
      DealTo(g, c);
      if g.pl[c].handN = 0 then EndTurn(g)
      else begin
        g.turn := c;
        g.ph := phDraw
      end
    end
    else EndTurn(g)
  end
end;

procedure LegalMoves(var g: Game; var ml: MoveList);
var i: integer; t: Target;
begin
  ml.n := 0;
  if g.ph = phPlay then
    for i := 1 to g.pl[g.turn].handN do
      for t := tgSelf to tgDiscard do
        if CheckPlay(g, i, t) = ErrOK then begin
          ml.n := ml.n + 1;
          ml.m[ml.n].hand := i;
          ml.m[ml.n].tgt := t
        end
end;

function DiscardValue(k: CardKind): integer;
begin
  if IsSafety(k) then DiscardValue := -50
  else if IsHazard(k) then DiscardValue := 5
  else if IsRemedy(k) then DiscardValue := 7
  else DiscardValue := 6
end;

function SafetyValue(var g: Game; s: integer; k: CardKind): integer;
var needed: boolean;
begin
  needed := false;
  if (k = sfAce) and (g.pl[s].battle = hzAccident) then needed := true;
  if (k = sfTank) and (g.pl[s].battle = hzOutOfGas) then needed := true;
  if (k = sfPunct) and (g.pl[s].battle = hzFlat) then needed := true;
  if (k = sfRoW) and ((g.pl[s].battle = hzStop) or g.pl[s].limited) then needed := true;
  if needed then SafetyValue := 100
  else if g.deckNext > NumCards then SafetyValue := 85    { no coup chances left: bank it }
  else SafetyValue := 20                                    { hold it for a coup fourre }
end;

{ Priority: cure > win > Go > mileage > attack > end limit > hold safety > discard. }
function MoveValue(var g: Game; var mv: PlayMove): integer;
var s, v: integer; k: CardKind;
begin
  s := g.turn;
  k := g.pl[s].hand[mv.hand];
  if mv.tgt = tgDiscard then MoveValue := DiscardValue(k)
  else if mv.tgt = tgOpponent then begin
    if k = hzLimit then MoveValue := 55
    else if k = hzStop then MoveValue := 70
    else MoveValue := 75
  end
  else if IsDistance(k) then begin
    v := DistValue(k);
    if g.pl[s].miles + v = TripMiles then MoveValue := 99
    else if k = ck200 then MoveValue := 30
    else MoveValue := 40 + v div 5
  end
  else if IsSafety(k) then MoveValue := SafetyValue(g, s, k)
  else if k = rmGo then MoveValue := 92
  else if k = rmEndLimit then MoveValue := 60
  else MoveValue := 95
end;

procedure AIChoose(var g: Game; var mv: PlayMove);
var ml: MoveList; i, best, bv, v: integer;
begin
  LegalMoves(g, ml);
  best := 1;
  bv := -1000;
  for i := 1 to ml.n do begin
    v := MoveValue(g, ml.m[i]);
    if v > bv then begin
      bv := v;
      best := i
    end
  end;
  mv := ml.m[best]
end;

procedure RandomChoose(var g: Game; var mv: PlayMove);
var ml: MoveList;
begin
  LegalMoves(g, ml);
  mv := ml.m[1 + RandBelow(g, ml.n)]
end;

{ Returns 0 when the game state is self-consistent, else a code identifying the problem. }
function CheckInvariants(var g: Game): integer;
var p, tot, r: integer;
begin
  r := 0;
  tot := RemainingDeck(g);
  for p := 0 to 1 do begin
    tot := tot + g.pl[p].handN;
    if (g.pl[p].handN < 0) or (g.pl[p].handN > 7) then r := 1;
    if (g.pl[p].miles < 0) or (g.pl[p].miles > TripMiles) then r := 2;
    if (g.pl[p].n200 < 0) or (g.pl[p].n200 > Max200) then r := 3
  end;
  if tot + g.gone <> NumCards then r := 4;
  CheckInvariants := r
end;

```python
#!/usr/bin/env python3
"""Reject Pascal constructs outside the conservative Lisa Pascal subset."""
import re
import sys

FORBIDDEN = [
    (r"\bexit\s*\(", "exit(...) is not portable; restructure the code"),
    (r"\binc\s*\(", "inc() is not available in Lisa Pascal"),
    (r"\bdec\s*\(", "dec() is not available in Lisa Pascal"),
    (r"\bbreak\b", "break is not available in Lisa Pascal"),
    (r"\bcontinue\b", "continue is not available in Lisa Pascal"),
    (r"\bshl\b", "shl is not available in Lisa Pascal"),
    (r"\bshr\b", "shr is not available in Lisa Pascal"),
    (r"\bresult\b", "Result is Free Pascal only; assign to the function name"),
    (r"\botherwise\b", "otherwise differs between compilers; use if-chains"),
    (r"\buses\b", "MILES-LOGIC must not depend on any unit"),
]


def blank(match):
    return re.sub(r"[^\n]", " ", match.group(0))


def find_problems(text):
    problems = []
    lines = text.split("\n")
    for n, line in enumerate(lines, 1):
        if re.search(r"\{\$|\(\*\$", line):
            problems.append((n, "compiler directives are not portable"))
        if any(ord(ch) > 127 for ch in line):
            problems.append((n, "non-ASCII character"))
    code = re.sub(r"\(\*.*?\*\)", blank, text, flags=re.S)
    code = re.sub(r"\{.*?\}", blank, code, flags=re.S)
    code = re.sub(r"'[^'\n]*'", blank, code)
    for n, line in enumerate(code.split("\n"), 1):
        for pattern, message in FORBIDDEN:
            if re.search(pattern, line, flags=re.I):
                problems.append((n, message))
    return sorted(problems)


def main(argv):
    path = argv[1] if len(argv) > 1 else "src/MILES-LOGIC.TEXT"
    with open(path, encoding="utf-8") as handle:
        problems = find_problems(handle.read())
    for n, message in problems:
        print("%s:%d: %s" % (path, n, message))
    return 1 if problems else 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```
