# 1000 Miles — Phases 3-4 Implementation Plan (portable UI core + first launch + a playable game)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 1000 Miles tool you can launch from the Lisa Office System and play a full hand of against the computer, with mouse-only control.

**Architecture:** Everything that can be tested on the Mac is portable Pascal compiled unchanged on both machines: `MILES-LOGIC` (rules, done), `MILES-LAYOUT` (where everything is on screen, and what a click hit) and `MILES-CTRL` (what a click or a clock tick does to the game). The Lisa-only layer is thin: `MILES-GLOBALS` (constants, globals, Filer protocol), `MILES-DRAW` (QuickDraw) and `MILES-MAIN` (startup, event loop, menus), plus a phrase file and build scripts. The Lisa code follows the structure of the Minesweeper tool, which is the only proven example of a Lisa Office System tool we have.

**Tech Stack:** Lisa Pascal (Workshop 3.0), Free Pascal `-Mtp` for host tests, Python 3 (lint, sender), Lisa Alert Manager phrase files.

**Spec:** `docs/superpowers/specs/2026-10-09-1000-miles-design.md`. Hardware findings: `docs/spikes/phase1-pipeline.md`. Screen design (approved): `docs/mockups/`.

**Scope:** Phases 3-4 of the spec. Phase 5 (data-segment persistence / Set Aside resume, Print and Copy, hand-drawn 1-bit card icons, match target setting) and Phase 6 (Risk) get their own plans once this runs on the Lisa.

**Executing this plan:** Tasks 1-3 are ordinary test-first Mac work. Tasks 5-8 end at a **Lisa checkpoint**: Claude prepares the files and exact steps, **the user runs them on the Lisa** and reports compiler output / what they see, and Claude fixes and re-sends. Claude cannot compile or run Lisa code, so every Lisa-side file is unverified until its checkpoint; each checkpoint lists what "good" looks like.

## Global Constraints

- Cards are 54 x 48 pixels (3:4 on the Lisa's non-square pixels); window content is 640 x 310; seat 0 is the human (bottom of the table), seat 1 the computer (top).
- Mouse only. A hand click selects a card (it lifts 8 pixels); then a click on your side plays it on yourself, on the computer's side attacks, on the discard pile discards. Clicking the draw pile draws. Legal destinations for the selected card get a heavy outline.
- Portable units (`MILES-LOGIC`, `MILES-LAYOUT`, `MILES-CTRL`) obey the conservative subset enforced by `tools/lint_lisa_subset.py` (no `exit`, `inc`, `dec`, `break`, `continue`, `shl`, `shr`, `Result`, `otherwise`, unsized `string`, directives other than `(*$U file.OBJ *)`; `uses` may only name other `Miles...` units) and must give identical results on both machines. Lisa-only units (`GLOBALS`, `DRAW`, `MAIN`) may use the Lisa toolbox, `exit` and `otherwise`.
- Rules learned from real Lisa compiles (see `docs/lisa-build.md`): a function result must be scalar, subrange or pointer (error 118) so never a string or record; a `{ }` comment ends at the first `}` so never write a brace inside a comment; a unit that uses another unit must list, before it, every unit in that unit's interface uses-list; booleans are not short-circuited; the transfer script and Transfer program turn `-` in a Mac file name into `/` on the Lisa.
- Every user-visible string lives in the phrase file `src/MILES-ALERTS.TEXT`, none in Pascal source (numerals built in code are fine). Card art and names are original; the product name is "1000 Miles".
- Tool number 202 appears only in `src/MILES-MAKE.TEXT`; display name "1000 Miles".
- Host build flags `-Mtp -Cr -Co`; every host test and the simulator must pass with them. Commit messages end with: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`

## Decisions made in this plan (confirm or change)

- **D1 Alerts, not custom dialogs.** The Coup Fourre prompt, hand result, new-hand confirmation and rules screen are Alert Manager alerts from the phrase file (one OK/Cancel box, parameters via `ParamAlert`). This is far simpler and safer than Minesweeper's hand-built Field Editor dialogs, but the coup prompt shows card *names* instead of the pictures in the approved mockup. Pictures can come with Phase 5.
- **D2 Typographic cards first.** Cards are drawn with frames, numerals and short captions using the style cues from the mockup (distance = plain frame + big numeral, hazard = black card, remedy = double frame, safety = heavy frame with a black band). Hand-drawn 1-bit icons are Phase 5.
- **D3 No persistence yet.** The hand lives in program memory; closing the window loses it. Data-segment persistence (so Set Aside resumes the game), Print and Copy are Phase 5.
- **D4 The human always moves first in a new hand**; the computer's moves are paced about 0.6 seconds apart so you can follow them.
- **D5 Full repaint per action.** Simplest correct approach; optimize to dirty rectangles only if it is visibly slow at stock 5 MHz (Review Focus 5).

## Review Focus

Inputs and failure modes the tests below do not obviously exercise; each has a test or an explicit checkpoint step.

1. Clicks that must do nothing: during the computer's turn, while a Coup Fourre answer is pending, after the hand is over, and in the gaps between piles (Task 3 tests).
2. Hand over: scored exactly once even if the event is delivered twice; a new hand clears the selection but keeps the match totals (Task 3 tests).
3. The Filer protocol: closing the window (Set Aside / Put Away) and reopening it must not crash or draw into a missing window; `myWindow = nil` must be guarded everywhere (Task 6 step 12 and Task 8 row 13).
4. Name or uses-list collisions with the Lisa's own units (`Box`, `Game`, `Target`, `Phase` ...): found only by the Lisa compile; fix by renaming with a `Mi` prefix and add a lint rule (Tasks 5-6).
5. Repaint speed on a 5 MHz Lisa and captions wider than a 54-pixel card (Task 7 checkpoint steps).

```pascal
{ MILES-LAYOUT: where everything sits on the 1000 Miles table, in window-local pixels,  }
{ and which thing a mouse click landed on.  No Lisa units: the same file is tested on   }
{ the Mac and compiled on the Lisa.  Boxes follow QuickDraw: right and bottom are the   }
{ first pixel OUTSIDE the box.  Seat 0 is the human (bottom of the screen), seat 1 the  }
{ computer (top).                                                                       }
unit MilesLayout;

interface

const
  ContentW = 640;
  ContentH = 310;
  CardW = 54;
  CardH = 48;

  SlotBattle  = 0;
  SlotSpeed   = 1;
  SlotSafety0 = 2;      { safeties occupy slots 2..5 in the order Ace, Tank, Tough, RoW }
  SlotMiles   = 6;
  NumSlots    = 7;

type
  Box = record
    left, top, right, bottom : integer;
  end;

  HitKind = (hkNone, hkHand, hkDraw, hkDiscard, hkOwn, hkOpp);

  HitInfo = record
    kind  : HitKind;
    index : integer;      { hand card 1..7 for hkHand, else 0 }
  end;

procedure SlotBox(seat, slot: integer; var b: Box);
procedure HandBox(i: integer; lifted: boolean; var b: Box);
procedure DrawPileBox(var b: Box);
procedure DiscardBox(var b: Box);
procedure OppHandBox(i: integer; var b: Box);
procedure RegionBox(seat: integer; var b: Box);
procedure BoxCenter(var b: Box; var x, y: integer);
function  PointInBox(x, y: integer; var b: Box): boolean;
procedure HitTest(x, y, handN, sel: integer; var hit: HitInfo);

implementation

const
  CompRowY   = 20;
  MidRowY    = 76;
  PlayerRowY = 145;
  HandRowY   = 214;
  HandLift   = 8;
  HandStep   = 62;
  HandX      = 8;
  OppHandX   = 450;
  OppHandStep = 22;

function RowY(seat: integer): integer;
begin
  if seat = 0 then RowY := PlayerRowY else RowY := CompRowY
end;

function SlotX(slot: integer): integer;
begin
  SlotX := 8;
  if slot = SlotBattle then SlotX := 8;
  if slot = SlotSpeed then SlotX := 68;
  if (slot >= SlotSafety0) and (slot < SlotMiles) then SlotX := 136 + 58 * (slot - SlotSafety0);
  if slot = SlotMiles then SlotX := 380
end;

procedure SetBox(var b: Box; l, t, r, bt: integer);
begin
  b.left := l; b.top := t; b.right := r; b.bottom := bt
end;

procedure SlotBox(seat, slot: integer; var b: Box);
var x, y: integer;
begin
  x := SlotX(slot);
  y := RowY(seat);
  SetBox(b, x, y, x + CardW, y + CardH)
end;

procedure HandBox(i: integer; lifted: boolean; var b: Box);
var x, y: integer;
begin
  x := HandX + (i - 1) * HandStep;
  y := HandRowY;
  if lifted then y := y - HandLift;
  SetBox(b, x, y, x + CardW, y + CardH)
end;

{ The draw pile is a stack of cards drawn offset up and to the right, so its box is bigger. }
procedure DrawPileBox(var b: Box);
begin
  SetBox(b, 8, MidRowY - 4, 8 + CardW + 4, MidRowY + CardH)
end;

procedure DiscardBox(var b: Box);
begin
  SetBox(b, 68, MidRowY, 68 + CardW, MidRowY + CardH)
end;

procedure OppHandBox(i: integer; var b: Box);
var x: integer;
begin
  x := OppHandX + (i - 1) * OppHandStep;
  SetBox(b, x, CompRowY, x + CardW, CompRowY + CardH)
end;

{ The band a click counts as "on that player's side of the table". }
procedure RegionBox(seat: integer; var b: Box);
begin
  SetBox(b, 0, RowY(seat) - 8, ContentW, RowY(seat) + CardH + 4)
end;

procedure BoxCenter(var b: Box; var x, y: integer);
begin
  x := (b.left + b.right) div 2;
  y := (b.top + b.bottom) div 2
end;

function PointInBox(x, y: integer; var b: Box): boolean;
begin
  PointInBox := (x >= b.left) and (x < b.right) and (y >= b.top) and (y < b.bottom)
end;

procedure HitTest(x, y, handN, sel: integer; var hit: HitInfo);
var i: integer; b: Box;
begin
  hit.kind := hkNone;
  hit.index := 0;
  for i := 1 to handN do begin
    HandBox(i, i = sel, b);
    if PointInBox(x, y, b) then begin
      hit.kind := hkHand;
      hit.index := i
    end
  end;
  if hit.kind = hkNone then begin
    DrawPileBox(b);
    if PointInBox(x, y, b) then hit.kind := hkDraw
  end;
  if hit.kind = hkNone then begin
    DiscardBox(b);
    if PointInBox(x, y, b) then hit.kind := hkDiscard
  end;
  if hit.kind = hkNone then begin
    RegionBox(0, b);
    if PointInBox(x, y, b) then hit.kind := hkOwn
  end;
  if hit.kind = hkNone then begin
    RegionBox(1, b);
    if PointInBox(x, y, b) then hit.kind := hkOpp
  end
end;

end.
```

```pascal
procedure PlayThrough(seed: longint; var steps: integer; var bad: integer);
var ev: UIEvent; mv: PlayMove; b: Box; k: CardKind; answer: integer;
begin
  UIInit(u);
  UINewHand(u, g, seed);
  steps := 0; bad := 0; answer := 0;
  while (g.ph <> phOver) and (steps < 4000) and (bad = 0) do begin
    steps := steps + 1;
    if g.ph = phCoup then begin
      if g.coupSeat = 0 then begin
        answer := answer + 1;
        UICoupAnswer(u, g, odd(answer), ev)
      end
      else UIAdvance(u, g, ev)
    end
    else if g.turn = 1 then
      UIAdvance(u, g, ev)
    else if g.ph = phDraw then begin
      DrawPileBox(b);
      ClickBox(b, ev);
      if ev <> ueDrew then bad := 1
    end
    else begin
      AIChoose(g, mv);
      k := g.pl[0].hand[mv.hand];
      HandBox(mv.hand, false, b);
      ClickBox(b, ev);
      if ev <> ueSelect then bad := 2;
      if bad = 0 then begin
        if mv.tgt = tgDiscard then DiscardBox(b)
        else if mv.tgt = tgSelf then SlotBox(0, NaturalSlot(k), b)
        else SlotBox(1, NaturalSlot(k), b);
        ClickBox(b, ev);
        if (ev <> ueMoved) and (ev <> ueHandOver) then bad := 3
      end
    end;
    if bad = 0 then bad := CheckInvariants(g) * 10
  end;
  if g.ph <> phOver then bad := 99
end;

procedure TestScriptedGames;
```

```pascal
{ MILES-CTRL: what a mouse click or a tick of the clock DOES to the game.  Human = seat 0,   }
{ computer = seat 1.  No Lisa units: tested on the Mac, compiled unchanged on the Lisa.     }
{ The Lisa program only turns events into calls here and draws the result.                  }
unit MilesCtrl;

interface

uses (*$U MILES/LOGIC.OBJ *) MilesLogic,
     (*$U MILES/LAYOUT.OBJ *) MilesLayout;

const
  { Status codes 1..12 are the Err* codes of MilesLogic; these are the UI's own. }
  MsgNone         = 0;
  MsgYourDraw     = 20;
  MsgYourPlay     = 21;
  MsgComputerTurn = 22;
  MsgComputerCoup = 23;
  MsgHandOver     = 24;
  MsgCoupAsk      = 25;
  MsgAlreadyDrew  = 26;

type
  UIEvent = (ueNone, ueSelect, ueDeselect, ueDrew, ueMoved, ueRejected, ueCoupPrompt, ueHandOver);

  UIState = record
    sel        : integer;                 { selected hand card, 0 = none }
    msg        : integer;                 { a message to show until the next action, or MsgNone }
    handScored : boolean;                 { this hand's points are already in match[] }
    match      : array[0..1] of longint;  { running match totals }
  end;

procedure UIInit(var u: UIState);
procedure UINewHand(var u: UIState; var g: Game; seed: longint);
procedure UIClick(var u: UIState; var g: Game; x, y: integer; var ev: UIEvent);
procedure UIAdvance(var u: UIState; var g: Game; var ev: UIEvent);
procedure UICoupAnswer(var u: UIState; var g: Game; useCoup: boolean; var ev: UIEvent);
function  NaturalSlot(k: CardKind): integer;
function  StatusMsg(var u: UIState; var g: Game): integer;

implementation

procedure UIInit(var u: UIState);
begin
  u.sel := 0;
  u.msg := MsgNone;
  u.handScored := false;
  u.match[0] := 0;
  u.match[1] := 0
end;

procedure UINewHand(var u: UIState; var g: Game; seed: longint);
begin
  NewGame(g, seed);
  u.sel := 0;
  u.msg := MsgNone;
  u.handScored := false
end;

{ Which pile a card naturally lands on; the screen highlights it. }
function NaturalSlot(k: CardKind): integer;
begin
  NaturalSlot := SlotBattle;
  if IsDistance(k) then NaturalSlot := SlotMiles;
  if k = rmEndLimit then NaturalSlot := SlotSpeed;
  if k = hzLimit then NaturalSlot := SlotSpeed;
  if IsSafety(k) then NaturalSlot := SlotSafety0 + SafetyIdx(k)
end;

{ When the hand has ended, score it exactly once and report ueHandOver. }
procedure Finish(var u: UIState; var g: Game; var ev: UIEvent);
begin
  if g.ph = phOver then begin
    if not u.handScored then begin
      u.match[0] := u.match[0] + HandPoints(g, 0);
      u.match[1] := u.match[1] + HandPoints(g, 1);
      u.handScored := true
    end;
    u.sel := 0;
    ev := ueHandOver
  end
end;

procedure UIClick(var u: UIState; var g: Game; x, y: integer; var ev: UIEvent);
var hit: HitInfo; err: integer; t: Target;
begin
  ev := ueNone;
  if (g.ph = phDraw) and (g.turn = 0) then begin
    HitTest(x, y, g.pl[0].handN, 0, hit);
    if hit.kind = hkDraw then begin
      DrawCard(g);
      u.msg := MsgNone;
      ev := ueDrew
    end
    else begin
      u.msg := ErrPhase;
      ev := ueRejected
    end
  end
  else if (g.ph = phPlay) and (g.turn = 0) then begin
    HitTest(x, y, g.pl[0].handN, u.sel, hit);
    if hit.kind = hkHand then begin
      u.msg := MsgNone;
      if hit.index = u.sel then begin
        u.sel := 0;
        ev := ueDeselect
      end
      else begin
        u.sel := hit.index;
        ev := ueSelect
      end
    end
    else if hit.kind = hkDraw then begin
      u.msg := MsgAlreadyDrew;
      ev := ueRejected
    end
    else if (hit.kind = hkOwn) or (hit.kind = hkOpp) or (hit.kind = hkDiscard) then begin
      if u.sel = 0 then begin
        u.msg := ErrNoCard;
        ev := ueRejected
      end
      else begin
        if hit.kind = hkOwn then t := tgSelf
        else if hit.kind = hkOpp then t := tgOpponent
        else t := tgDiscard;
        DoPlay(g, u.sel, t, err);
        if err = ErrOK then begin
          u.sel := 0;
          u.msg := MsgNone;
          ev := ueMoved;
          if g.ph = phCoup then begin       { the computer is the victim: it always answers }
            ResolveCoup(g, true);
            u.msg := MsgComputerCoup
          end;
          Finish(u, g, ev)
        end
        else begin
          u.msg := err;
          ev := ueRejected
        end
      end
    end
  end
end;

{ One computer action.  The Lisa program calls this on a timer so moves are visible. }
procedure UIAdvance(var u: UIState; var g: Game; var ev: UIEvent);
var mv: PlayMove; err: integer;
begin
  ev := ueNone;
  if g.ph = phCoup then begin
    if g.coupSeat = 0 then begin
      u.msg := MsgCoupAsk;
      ev := ueCoupPrompt
    end
    else begin
      ResolveCoup(g, true);
      u.msg := MsgComputerCoup;
      ev := ueMoved;
      Finish(u, g, ev)
    end
  end
  else if (g.ph = phDraw) and (g.turn = 1) then begin
    DrawCard(g);
    u.msg := MsgNone;
    ev := ueDrew
  end
  else if (g.ph = phPlay) and (g.turn = 1) then begin
    AIChoose(g, mv);
    DoPlay(g, mv.hand, mv.tgt, err);
    u.msg := MsgNone;
    ev := ueMoved;
    if g.ph = phCoup then begin
      if g.coupSeat = 0 then begin
        u.msg := MsgCoupAsk;
        ev := ueCoupPrompt
      end
    end;
    Finish(u, g, ev)
  end
  else if g.ph = phOver then
    Finish(u, g, ev)
end;

procedure UICoupAnswer(var u: UIState; var g: Game; useCoup: boolean; var ev: UIEvent);
begin
  ev := ueMoved;
  ResolveCoup(g, useCoup);
  u.msg := MsgNone;
  Finish(u, g, ev)
end;

function StatusMsg(var u: UIState; var g: Game): integer;
begin
  if u.msg <> MsgNone then StatusMsg := u.msg
  else if g.ph = phOver then StatusMsg := MsgHandOver
  else if g.ph = phCoup then StatusMsg := MsgCoupAsk
  else if g.turn = 1 then StatusMsg := MsgComputerTurn
  else if g.ph = phDraw then StatusMsg := MsgYourDraw
  else StatusMsg := MsgYourPlay
end;

end.
```

```python
#!/usr/bin/env python3
"""Reject Pascal constructs that Lisa Pascal may not accept.

Two profiles:
  portable (default)  the units that also compile on the Mac (LOGIC, LAYOUT, CTRL): a conservative
                      subset, plus 'uses' may only name other MilesXxx units.
  --lisa-only         the units that only ever compile on the Lisa (GLOBALS, DRAW, MAIN): they use
                      Lisa toolbox units, exit(), otherwise, etc.; only mistakes the Lisa compiler
                      is known to reject are checked.
"""
import re
import sys

PORTABLE_RULES = [
    (r"\bexit\s*\(", "exit(...) is not portable; restructure the code"),
    (r"\binc\s*\(", "inc() is not available in Lisa Pascal"),
    (r"\bdec\s*\(", "dec() is not available in Lisa Pascal"),
    (r"\bbreak\b", "break is not available in Lisa Pascal"),
    (r"\bcontinue\b", "continue is not available in Lisa Pascal"),
    (r"\bshl\b", "shl is not available in Lisa Pascal"),
    (r"\bshr\b", "shr is not available in Lisa Pascal"),
    (r"\bresult\b", "Result is Free Pascal only; assign to the function name"),
    (r"\botherwise\b", "otherwise differs between compilers; use if-chains"),
    (r"\bstring\b(?!\s*\[)", "unsized string: declare a sized one such as string[63]"),
]

# Found by compiling on a real Lisa (error 118): a function result must be scalar, subrange or pointer.
LISA_RULES = [
    (r"\bfunction\b[^;]*:\s*(?:string|ErrStr|CapStr|Str255)\s*(?:\[[^\]]*\])?\s*;",
     "a function cannot return a string (Lisa Pascal error 118); use a procedure with a var parameter"),
]

ALLOWED_DIRECTIVE = re.compile(r"\(\*\$U [^*]*\*\)")      # (*$U MILES/LOGIC.OBJ *) names a unit's object file


def blank(match):
    return re.sub(r"[^\n]", " ", match.group(0))


def brace_comment_problems(text):
    """A { comment ends at the FIRST }, so a stray { or } inside one turns the rest into code."""
    problems = []
    i, n, line = 0, len(text), 1
    while i < n:
        c = text[i]
        if c == "\n":
            line += 1
        if c == "'":                                   # skip a string literal
            j = i + 1
            while j < n and text[j] != "'" and text[j] != "\n":
                j += 1
            i = j + 1
            continue
        if c == "{":
            j = i + 1
            while j < n and text[j] != "}":
                if text[j] == "{":
                    problems.append((line, "'{' inside a { } comment ends it early"))
                if text[j] == "\n":
                    line += 1
                j += 1
            i = j + 1
            continue
        i += 1
    return problems


def find_problems(text, lisa_only=False):
    problems = []
    for n, line in enumerate(text.split("\n"), 1):
        if any(ord(ch) > 127 for ch in line):
            problems.append((n, "non-ASCII character"))
        if not lisa_only and re.search(r"\{\$|\(\*\$(?!U )", line):
            problems.append((n, "compiler directives are not portable"))
    problems += brace_comment_problems(text)
    code = re.sub(r"\(\*.*?\*\)", blank, text, flags=re.S)       # this also removes (*$U ... *)
    code = re.sub(r"\{.*?\}", blank, code, flags=re.S)
    code = re.sub(r"'[^'\n]*'", blank, code)
    rules = LISA_RULES if lisa_only else PORTABLE_RULES + LISA_RULES
    for n, line in enumerate(code.split("\n"), 1):
        for pattern, message in rules:
            if re.search(pattern, line, flags=re.I):
                problems.append((n, message))
    if not lisa_only:
        for m in re.finditer(r"\buses\b([^;]*);", code, flags=re.I):
            line = code.count("\n", 0, m.start()) + 1
            for name in m.group(1).split(","):
                if not re.fullmatch(r"\s*Miles[A-Za-z0-9]*\s*", name, flags=re.I):
                    problems.append((line, "portable units may only use other Miles units, not '%s'" % name.strip()))
    return sorted(set(problems))


def main(argv):
    args = argv[1:]
    lisa_only = "--lisa-only" in args
    paths = [a for a in args if not a.startswith("--")] or ["src/MILES-LOGIC.TEXT"]
    bad = 0
    for path in paths:
        with open(path, encoding="utf-8") as handle:
            problems = find_problems(handle.read(), lisa_only)
        for n, message in problems:
            print("%s:%d: %s" % (path, n, message))
        bad += len(problems)
    return 1 if bad else 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

```pascal
{ Non-negative number to decimal text, no leading zeros.  These are NUMERALS, not    }
{ language, so building them in code does not break the no-literal-strings rule.    }
procedure NumToStr {n : longint; var s : Str255};
var divisor : longint;
    d       : integer;
    started : boolean;
begin
   if n < 0 then n := 0;
   s := '';
   divisor := 1000000000;
   started := false;
   while divisor > 0 do begin
      d := (n div divisor) mod 10;
      if (d <> 0) or started or (divisor = 1) then begin
         s := concat(s, ' ');
         s[length(s)] := chr(ord('0') + d);
         started := true
      end;
      divisor := divisor div 10
   end
end;

procedure GetPhrase {n : integer; var s : Str255};
begin
   s := '';
   GetAlert(allAlerts, n, @s)
end;

    t : Str255;
begin

      GetPhrase(phCardBase + ord(k), t);
      capText[k] := copy(t, 1, 15)
   end;

   GetPhrase(phYou, t);       lblYou      := copy(t, 1, 15);
   GetPhrase(phMiles, t);     lblMiles    := copy(t, 1, 15);

end;

{ The Filer protocol.  EVERY Filer command must be answered, or the whole desktop      }
{ freezes.  fcNone is the only one that needs the main program: it lends us a window.  }
procedure HandleFilerOp {var wantsOpen : boolean};
var fx  : FilerExt;
    err : integer;
begin
   wantsOpen := false;
   GetAddParms(err, theEvent, fx);
   case fx.theFlrOp of
      fcNone :
         wantsOpen := true;
      fcResume :
         TellFiler(err, docClosd, internalError, theEvent.who);
      fcClose, fcSuspend, fcShred :

            TellFiler(err, docClosd, allOK, theEvent.who)
         end;
      fcCopy, fcPut :
         TellFiler(err, docNotXfered, internalError, theEvent.who);
      fcDfClose :
         TellFiler(err, dfClosed, allOK, theEvent.who);
      fcTerminate :
         toldToDie := true;

   end
```

```pascal
{  Initialize -- the order of these steps matters.  On any failure we tell the   }
{  Filer we never got started and halt.                                         }

    schedErr : integer;
    pcInfo   : procinfoRec;
    excName  : t_ex_name;
    myPrefix : TParamAlert;
    cutAt    : integer;
begin
   initing := true;

   { (1) FIRST: the terminate handler, before anything that could fail. }
   excName := 'SYS_TERMINATE';
   Declare_Excep_Hdl(err, excName, @LastWishes);
   if err <> 0 then begin
      TellFiler(err, initFailed, noMemory, nil);
      halt
   end;

   { (2) Known state for our flags. }
   toldToDie := false;
   myWindow  := nil;
   haveGame  := false;
   nextAi    := 0;
   UIInit(ui);

   { (3) The private heap, carved out of the static myZone array. }
   InitHeap(@myZone[0], @myZone[maxHeap], @OutOfHeapSpace);

   { (4) Who am I, and where on disk?  Info_Process may block, so drop to preemptive }
   { scheduling around it.                                                         }
   Sched_Class(schedErr, false);
   Info_Process(err, My_ID, pcInfo);
   Sched_Class(schedErr, true);

   { name that begins with the tool number in curly braces, so our own pathname      }
   { already carries it.  Keep everything through the closing brace character.     }
   cutAt := pos('}', pcInfo.progpathname);
   if (cutAt = 0) or (cutAt > 40) then begin
      TellFiler(err, initFailed, internalError, nil);
      halt
   end;
   myPrefix := copy(pcInfo.progpathname, 1, cutAt);

   { (6) Menus and alerts: InitMP opens "<myPrefix>PHRASE", installs the menu blocks }
   { into myMenus, and loads the alert directory.                                   }
   InitMP(theHeap, myPrefix, @AlertFailed, alertVerNum,
          @myMenus[mFile], allAlerts, err);
   if err > 0 then begin
      TellFiler(err, initFailed, noMemory, nil);
      halt
   end;
   LoadCaptions;

   { (7) The standard cursor shapes. }
   InitWmlCrs(err);
   if err <> 0 then begin
      TellFiler(err, initFailed, noDiskSpace, nil);
      halt
   end;

   { (8) A guaranteed-valid current port before any drawing. }
   SetPort(deskPort);

   initing := false
end;

{==============================================================================}

begin
   InitGraf(@thePort);      { QuickDraw for THIS process }
   OpenWm;                  { attach to the Window Manager }
   Initialize;

   repeat
      { Phase A: we are not the active window.  GetEvent blocks and may suspend us. }
      while not (ImActive or toldToDie) do begin
         GetEvent(theEvent);
         ProcessTheEvent
      end;

      { Phase B: we ARE active.  Poll; when idle, do periodic work and then yield. }
      while ImActive and (not toldToDie) do begin
         if EventAvail then begin
            GetEvent(theEvent);
            ProcessTheEvent
         end
         else begin
            DoComputerStep;
            LetOthersRun         { NEVER omitted: the scheduler is cooperative }
         end
      end;

   until toldToDie
end.
```

```pascal
{ with a big numeral; hazard = BLACK card; remedy = double frame; safety = heavy frame  }
{ with a black band.                                                                    }
unit MilesDraw;

INTERFACE

uses (*$U UnitStd.obj *)        UnitStd,
     (*$U UnitHz.obj *)         UnitHz,
     (*$U Storage.obj *)        Storage,
     (*$U QuickDraw.obj *)      QuickDraw,
     (*$U Fontmgr.obj *)        FontMgr,
     (*$U SysCall.obj *)        SysCall,
     (*$U wm.events.obj *)      Events,
     (*$U wm.folders.obj *)     Folders,
     (*$U wm.menus.obj *)       Menus,
     (*$U AlertMgr.obj *)       AlertMgr,
     (*$U WMLstd.obj *)         WMLstd,
     (*$U WMlCrs.obj *)         WMLCrs,
     (*$U FilerComm.obj *)      FilerComm,
     (*$U MILES/LOGIC.OBJ *)    MilesLogic,
     (*$U MILES/LAYOUT.OBJ *)   MilesLayout,
     (*$U MILES/CTRL.OBJ *)     MilesCtrl,
     (*$U MILES/GLOBALS.OBJ *)  MilesGlobals;

{ Repaint the whole table into the window (or the update region while updating). }
procedure DrawContents (window : WindowPtr);

IMPLEMENTATION

const
   statusLineY = 274;
   statusTextY = 291;

procedure BoxToRect (var b : Box; var r : Rect);
begin
   { SetRect takes left, top, right, bottom -- NOT the record's field order. }
   SetRect(r, b.left, b.top, b.right, b.bottom)
end;

procedure CenterString (var r : Rect; baseline : integer; var s : Str255);
begin
   MoveTo(r.left + ((r.right - r.left) - StringWidth(s)) div 2, baseline);
   DrawString(s)
end;

{ A card back: a gray tile with a frame. }
procedure DrawCardBack (var r : Rect);
begin
   PenNormal;
   FillRect(r, gray);
   FrameRect(r)
end;

{ An empty pile: a gray outline. }
procedure DrawEmptySlot (var r : Rect);
begin
   EraseRect(r);
   PenNormal;
   PenPat(gray);
   FrameRect(r);
   PenPat(black)
end;

{ The thick outline that shows where the selected card can legally go. }
procedure DrawHighlight (var r : Rect);
var o : Rect;
begin
   o := r;
   InsetRect(o, -4, -4);
   PenNormal;
   PenSize(2, 2);
   FrameRect(o);
   PenNormal
end;

procedure DrawCardFace (k : CardKind; var r : Rect);
var s     : Str255;
    fi    : FontInfo;
    inner : Rect;
    band  : Rect;
    mid   : integer;
begin
   PenNormal;
   EraseRect(r);
   TextMode(srcOr);
   TextFace([]);
   if IsDistance(k) then begin
      FrameRect(r);
      TextFont(fntBig);
      GetFontInfo(fi);
      NumToStr(DistValue(k), s);
      CenterString(r, r.top + 6 + fi.ascent, s);
      TextFont(fntCaption);
      GetFontInfo(fi);
      s := capText[k];
      CenterString(r, r.bottom - 6 - fi.descent, s)
   end
   else begin
      TextFont(fntCaption);
      GetFontInfo(fi);
      s := capText[k];
      if IsSafety(k) then begin
         PenSize(2, 2);
         FrameRect(r);
         PenNormal;
         SetRect(band, r.left + 2, r.bottom - 14, r.right - 2, r.bottom - 2);
         PaintRect(band);
         mid := r.top + (CardH - 14 + fi.ascent - fi.descent) div 2;
         CenterString(r, mid, s)
      end
      else begin
         FrameRect(r);
         if IsRemedy(k) then begin
            inner := r;
            InsetRect(inner, 3, 3);
            FrameRect(inner)
         end;
         mid := r.top + (CardH + fi.ascent - fi.descent) div 2;
         CenterString(r, mid, s);
         if IsHazard(k) then
            InvertRect(r)              { hazards are black cards with white text }
      end
   end
end;

{ The miles-travelled box: a framed number. }
procedure DrawMilesBox (miles : integer; var r : Rect);
var s  : Str255;
    fi : FontInfo;
begin
   PenNormal;
   EraseRect(r);
   FrameRect(r);
   TextMode(srcOr);
   TextFace([]);
   TextFont(fntBig);
   GetFontInfo(fi);
   NumToStr(miles, s);
   CenterString(r, r.top + 6 + fi.ascent, s);
   TextFont(fntCaption);
   GetFontInfo(fi);
   s := lblMiles;
   CenterString(r, r.bottom - 6 - fi.descent, s)
end;

{ One player's row: header (name, trip bar, miles), the seven piles, and for the }
{ computer the backs of its cards.                                              }
procedure DrawSide (seat : integer);
var b, hb  : Box;
    r, bar : Rect;
    s, t   : Str255;
    i, w   : integer;
    k      : CardKind;
begin
   SlotBox(seat, SlotBattle, hb);

   { header: the name, a 1000-mile trip bar, and the mileage as text }
   TextMode(srcOr);
   TextFace([bold]);
   TextFont(fntCaption);
   MoveTo(8, hb.top - 6);
   if seat = 0 then s := lblYou else s := lblComputer;
   DrawString(s);
   TextFace([]);
   SetRect(bar, 130, hb.top - 16, 430, hb.top - 7);
   PenNormal;
   FrameRect(bar);
   w := ord4(theGame.pl[seat].miles) * 298 div 1000;
   if w > 0 then begin
      SetRect(r, 131, bar.top + 1, 131 + w, bar.bottom - 1);
      PaintRect(r)
   end;
   NumToStr(theGame.pl[seat].miles, s);
   t := lblMiles;
   s := concat(s, ' / 1000 ', t);
   MoveTo(440, hb.top - 6);
   DrawString(s);

   { battle pile: the top card, or an empty outline }
   SlotBox(seat, SlotBattle, b);
   BoxToRect(b, r);
   if theGame.pl[seat].battle <> ckNone then DrawCardFace(theGame.pl[seat].battle, r)
   else DrawEmptySlot(r);

   { speed pile: a Speed Limit card while limited }
   SlotBox(seat, SlotSpeed, b);
   BoxToRect(b, r);
   if theGame.pl[seat].limited then DrawCardFace(hzLimit, r)
   else DrawEmptySlot(r);

   { the four safeties, in the order Ace, Tank, Puncture-proof, Right of Way }
   k := sfAce;
   for i := 0 to 3 do begin
      SlotBox(seat, SlotSafety0 + i, b);
      BoxToRect(b, r);
      if theGame.pl[seat].safe[i] then DrawCardFace(k, r)
      else DrawEmptySlot(r);
      if i < 3 then k := succ(k)
   end;

   { miles }
   SlotBox(seat, SlotMiles, b);
   BoxToRect(b, r);
   DrawMilesBox(theGame.pl[seat].miles, r);

   { the computer's hidden hand }
   if seat = 1 then
      for i := 1 to theGame.pl[1].handN do begin
         OppHandBox(i, b);
         BoxToRect(b, r);
         DrawCardBack(r)
      end
end;

procedure DrawMiddle;
var b    : Box;
    r, c : Rect;
    s, t : Str255;
    fi   : FontInfo;
    j    : integer;
begin
   { the draw pile: a small stack of backs with the count on top }
   DrawPileBox(b);
   for j := 2 downto 0 do begin
      SetRect(r, b.left + (2 - j) * 2, b.top + j * 2, b.left + (2 - j) * 2 + CardW, b.top + j * 2 + CardH);
      DrawCardBack(r)
   end;
   SetRect(c, r.left + 12, r.top + 15, r.right - 12, r.bottom - 15);
   EraseRect(c);
   FrameRect(c);
   TextFont(fntCaption);
   TextMode(srcOr);
   TextFace([]);
   GetFontInfo(fi);
   NumToStr(RemainingDeck(theGame), s);
   CenterString(c, c.top + (c.bottom - c.top + fi.ascent - fi.descent) div 2, s);

   { the discard pile }
   DiscardBox(b);
   BoxToRect(b, r);
   if theGame.discardTop <> ckNone then DrawCardFace(theGame.discardTop, r)
   else DrawEmptySlot(r);

   { the score line }
   TextFont(fntCaption);
   TextFace([bold]);
   s := lblMatch;
   MoveTo(136, b.top + 14);
   DrawString(s);
   TextFace([]);
   t := lblYou;
   NumToStr(ui.match[0], s);
   s := concat(t, ' ', s);
   MoveTo(136, b.top + 30);
   DrawString(s);
   t := lblComputer;
   NumToStr(ui.match[1], s);
   s := concat(t, ' ', s);
   MoveTo(136, b.top + 46);
   DrawString(s)
end;

procedure DrawHand;
var i    : integer;
    b    : Box;
    r    : Rect;
begin
   for i := 1 to theGame.pl[0].handN do begin
      HandBox(i, i = ui.sel, b);
      BoxToRect(b, r);
      DrawCardFace(theGame.pl[0].hand[i], r)
   end
end;

{ Outline the pile the selected card would naturally go to, on whichever side(s) allow it. }
procedure DrawTargets;
var k    : CardKind;
    b    : Box;
    r    : Rect;
    slot : integer;
begin
   if (ui.sel >= 1) and (theGame.ph = phPlay) and (theGame.turn = 0) then begin
      k := theGame.pl[0].hand[ui.sel];
      slot := NaturalSlot(k);
      if CheckPlay(theGame, ui.sel, tgSelf) = ErrOK then begin
         SlotBox(0, slot, b);
         BoxToRect(b, r);
         DrawHighlight(r)
      end;
      if CheckPlay(theGame, ui.sel, tgOpponent) = ErrOK then begin
         SlotBox(1, slot, b);
         BoxToRect(b, r);
         DrawHighlight(r)
      end
   end
end;

procedure DrawStatus;
var s : Str255;
begin
   PenNormal;
   MoveTo(0, statusLineY);
   LineTo(ContentW - 1, statusLineY);
   GetPhrase(phStatusBase + StatusMsg(ui, theGame), s);
   TextFont(fntCaption);
   TextMode(srcOr);
   TextFace([]);
   MoveTo(8, statusTextY);
   DrawString(s)
end;

procedure DrawContents {window : WindowPtr};
var all : Rect;
begin
   if window = nil then exit(DrawContents);
   SetPort(window);
   SetRect(all, 0, 0, ContentW, ContentH);
   ClipRect(all);
   EraseRect(all);
   DrawSide(1);
   DrawMiddle;
   DrawSide(0);
   DrawHand;
   DrawTargets;
   DrawStatus
end;

end.
```
