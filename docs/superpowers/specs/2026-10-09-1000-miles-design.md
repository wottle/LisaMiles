# 1000 Miles — Design Spec

A Mille Bornes-style two-player card game (you vs. computer) for Apple Lisa Office System 3.0,
written in Lisa Pascal and installed as an Office System tool. Phase 2 (separate spec): Risk.

## Goals
- A fun, working Lisa game for the author's real Lisa / LisaFPGA, runnable in LisaEm where possible.
- A repeatable develop-and-test loop modeled on alexthecat123/los_minesweeper, plus fast host-side
  testing of the rules engine on the Mac.

## Non-goals (v1)
Four-player/team play, extension rounds, sound, networking, keyboard play.

## Reference: los_minesweeper conventions to reuse
- Lisa Pascal built on the Lisa in Workshop; source pushed over Serial B (28800 baud, RTS/CTS, DSR
  polled manually) by `tools/lisa_serial_transfer.py`; built with `<NAME/MAKE`.
- Units compile in dependency order (compiler reads interfaces from compiled `.OBJ`).
- `MAKE.TEXT` ($EXEC): submit COMP + LINK; install object as `T<n>Obj`; compile alerts to `T<n>PHRASE`;
  run InstallTool with exactly six answers (no document-making tool). Tool number only in MAKE.
- LINK libs: IOSPASLIB, SYS1LIB, SYS2LIB, PRLIB; omit IOSFPLIB (integer-only).
- Lifecycle: install `SYS_TERMINATE` handler first; `ImDying` first on exit; answer every Filer op;
  two-phase event loop (events, then idle work).
- State in a data segment (Set Aside persistence), version stamp, `DocIsSane` validation.
- Non-square pixels (~2/3 wide as tall). Manual dialogs. Print/Copy via QuickDraw picture recording
  (`PrTextUnscaled`).
- Lisa Pascal: no boolean short-circuit, 16-bit `integer`, `exit(procname)`.

## Architecture
```
src/  MILES-LOGIC.TEXT    portable rules engine + AI (no Lisa units)
      MILES-GLOBALS.TEXT  types/consts, data-segment doc, shared helpers
      MILES-DRAW.TEXT     QuickDraw rendering
      MILES-DIALOG.TEXT   manual dialogs (new game, rules, scoring, coup fourre prompt)
      MILES-MAIN.TEXT     Initialize, event loop, menus, Filer handshake
      MILES-COMP / LINK / MAKE / ALERTS .TEXT   (Minesweeper pattern; tool number != 201)
tools/      lisa_serial_transfer.py (reuse, with attribution/license check)
host_test/  Free Pascal harness: unit tests + seeded simulator
```
Build order: LOGIC -> GLOBALS -> DRAW -> DIALOG -> MAIN.

`MILES-LOGIC` has no dependency on Lisa units, takes an injected RNG seed, and is kept to a
conservative Pascal subset so the same file compiles under Free Pascal (16-bit integer mode)
and Lisa Pascal. Use `longint` for any sum that can exceed 32767.

## Rules (v1)
- Deck of 106 cards: 46 distance (25x10, 50x10, 75x10, 100x12, 200x4), 18 hazards, 38 remedies,
  4 safeties; original names/art.
- Two players, hand of 6; draw, then play or discard. Target exactly 1000 miles; max two 200-mile
  cards per player per hand.
- Hazards go on the opponent's battle/speed piles; remedies required before moving; safeties give
  permanent immunity. Coup fourre: prompt for human, automatic for AI.
- Hand ends at 1000 miles, or when the draw pile is empty and both players cannot play.
- Scoring: miles, safeties (more for coup fourre), trip-complete, delayed-action, safe-trip, shutout;
  running match total to a configurable target.
- Set Aside/resume restores the exact game state.

## Computer opponent
One rule-based AI, priority order: coup fourre; cure own hazard; best legal distance (save 200s);
attack when opponent is moving; hold safeties conditionally; discard least useful card.
A random-legal-move AI exists only for the simulator. Seeded RNG makes games reproducible across
Mac and Lisa.

## UI
Fixed ~640x330 window; no scroll bars or resize. Layout expressed in square-glass units and converted
in one place. Click a hand card to select, then click a highlighted legal destination (own piles,
opponent hazard/speed piles, discard); click draw pile to draw; illegal clicks show a reason in the
status bar. Menus: File (Print, Copy), Game (New Game, Rules, Match Target), Edit as required.
Art: QuickDraw primitives plus a few 1-bit icons; no external resources. Dirty-list redraw.
Computer turn runs from the idle phase with a short delay.

## Testing
1. Host (Mac): unit tests (deck composition, legal moves, coup fourre, safeties, scoring) and a seeded
   simulator of thousands of AI-vs-AI games checking invariants (no lost cards, scores add up, games
   terminate).
2. LisaEm: UI smoke tests if Workshop 3.0 compile/link works (reported unreliable; spike first).
3. Real Lisa / LisaFPGA: final authority.

## Phases
1. Spike: LisaEm Workshop 3.0 compile/link; verify Minesweeper pipeline end to end on real hardware.
2. LOGIC + host tests + simulator.
3. UI skeleton (window, menus, Filer handshake, static table).
4. Playable hand vs AI.
5. Polish (scoring dialogs, persistence, print/copy, rules screen).
6. Phase 2: Risk (separate spec), reusing the portable-engine + seeded-simulator pattern.

## Risks
- Lisa Pascal vs Free Pascal dialect differences (mitigation: conservative subset; Lisa compile is
  the real check).
- LisaEm Workshop linking issue (unverified claim).
- Lisa-specific QuickDraw/Filer code is written from Minesweeper patterns and cannot be compiled in
  the authoring environment; unverified until built on a Lisa/Workshop.
