# 1000 Miles - design mockups (for approval)

Regenerate with `python3 tools/mockups/render_mockups.py` (needs Pillow and Geneva.ttf).

| File | What it shows |
|---|---|
| `table_mid_game_glass.png` | The main table, as it would look on the Lisa tube |
| `card_set_glass.png` | All 19 card faces plus the card back, with names |
| `coup_fourre_dialog_glass.png` | The coup fourre prompt over the table |
| `*.png` (no `_glass`) | The same images pixel-exact, 720x364 |

## Why two versions of each
Lisa pixels are about 2/3 as wide as they are tall. The `_glass` images stretch every pixel
2 wide x 3 tall so shapes look as they do on the real display; the plain images are the
actual 1-bit bitmap the program draws.

## Design facts shown here
- Cards are 54 x 48 pixels, which is 3:4 on the glass. 7 cards fit in the hand row with room to spare.
- Hazards are inverted (black cards), remedies have a double border, safeties have a heavy
  frame with a black banner, distance cards show a large numeral. These cues work in 1-bit
  without relying on colour.
- Legal destinations for the selected card get a heavy outline (the player's battle pile here).
- Window frame, menu bar and desktop pattern are approximations; the real ones come from the
  Lisa Window Manager. Only the content area (638 x ~308) is ours.
- All artwork is original; icons are generated by `render_mockups.py` and will be re-drawn by
  hand as 1-bit bitmaps for the real build.
