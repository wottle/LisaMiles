$EXEC
${=============================================================================}
${ MILES-COMP.TEXT -- compile every 1000 Miles source in DEPENDENCY ORDER.      }
${ The compiler reads a used unit's interface out of its already-compiled .OBJ, }
${ so a unit must be compiled before anything that uses it:                     }
${   LOGIC -> LAYOUT -> CTRL -> GLOBALS -> DRAW -> MAIN                         }
${                                                                            }
${ Comment-only lines are written as exec lines (leading $) so they do not send }
${ a stray [RETURN] into the program that is reading input -- EXCEPT the one    }
${ under each Pascal command, which IS the [RETURN] answering "listing file?".  }
${ Stale .OBJ files are deleted first so an old object can never be reused.     }
${=============================================================================}
F{ilemgr}D{elete}MILES/LOGIC.OBJ  Y{es}
        D{elete}MILES/LAYOUT.OBJ  Y{es}
        D{elete}MILES/CTRL.OBJ  Y{es}
        D{elete}MILES/GLOBALS.OBJ  Y{es}
        D{elete}MILES/DRAW.OBJ  Y{es}
        D{elete}MILES/MAIN.OBJ  Y{es}
        Q{uit}
P{ascal Compile}MILES/LOGIC.TEXT
{no listing file - this comment-only line IS the [RETURN] answer}
MILES/LOGIC.OBJ
P{ascal Compile}MILES/LAYOUT.TEXT
{no listing file}
MILES/LAYOUT.OBJ
P{ascal Compile}MILES/CTRL.TEXT
{no listing file}
MILES/CTRL.OBJ
P{ascal Compile}MILES/GLOBALS.TEXT
{no listing file}
MILES/GLOBALS.OBJ
P{ascal Compile}MILES/DRAW.TEXT
{no listing file}
MILES/DRAW.OBJ
P{ascal Compile}MILES/MAIN.TEXT
{no listing file}
MILES/MAIN.OBJ
$ENDEXEC
